## Коротко о главном

- **Скачать нужно один файл** — [`tmntnet-launcher.exe`](https://github.com/int3re/TMNT-2003-COOP/releases/latest/download/tmntnet-launcher.exe).
  Он ставит мод, обновляет его и себя и запускает игру.
- **У всех игроков должен совпадать сетевой протокол мода.** Таблица версий — на
  [главной странице](../README.md#версии-и-совместимость); лаунчер показывает протокол рядом с
  версией.
- **Нужна своя копия игры**: файлы игры в репозиторий и релизы не входят.
- **Если что-то пошло не так**, пришлите `tmntnet.log` со всех ПК, участвовавших в игре:
  [как сообщить об ошибке](TROUBLESHOOTING.md).
