# Установка и удаление

[← На главную](../README.md) · [English](en/INSTALL.md)

## Что понадобится

- Windows 10 или 11.
- Установленная игра **Teenage Mutant Ninja Turtles (2003)** для PC. Мод не содержит файлов игры.
- Для игры через интернет — запущенный Steam (у каждого игрока свой аккаунт). Саму игру в Steam
  добавлять не нужно.

У всех, кто играет вместе, должны совпадать **версия мода** и **файл `TMNT.EXE`**. При
несовпадении мод не даст подключиться и напишет, в чём дело.

## Установка

Проще всего — [лаунчером](LAUNCHER.md):

1. Скачайте `tmntnet-launcher.exe` со страницы [релизов](../../../releases/latest) и запустите.
2. В окне уже указана папка игры (лаунчер находит её сам; **Изменить** — выбрать вручную).
   Нажмите **УСТАНОВИТЬ МОД**. Интернет для этого не нужен: установщик лежит внутри лаунчера.

Дальше игру можно запускать кнопкой **ИГРАТЬ** в лаунчере или как раньше, своим ярлыком.

![Лаунчер: мод не установлен, кнопка «Установить мод»](images/launcher-install.png)

Без лаунчера то же самое делает установщик `tmntnet-setup.exe` из того же релиза: закройте
игру, запустите его и нажмите **«Установить мод»** (кнопка **«Другая папка»** — выбрать папку
игры вручную).

Если игра стоит в `Program Files`, Windows попросит права администратора.

> [!NOTE]
> Лаунчер и установщик не подписаны сертификатом, поэтому Windows может показать окно «Система Windows
> защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**. Контрольная
> сумма SHA-256 файла указана в описании каждого релиза; исходный код лежит в `src/launcher` и
> `src/setup`.

После установки мод сразу включает рекомендованные настройки экрана: окно без рамки на весь
монитор, разрешение рабочего стола, широкий формат, сглаживание 4x. Всё это меняется в игре:
**ПАРАМЕТРЫ → ПАРАМЕТРЫ ГРАФИКИ**.

### Что появляется в папке игры

| Файл | Что это |
|---|---|
| `winmm.dll` | [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader): загружает мод при старте игры |
| `tmntnet.asi` | сам мод |
| `tmntnet.ini` | настройки (см. [справочник](SETTINGS.md)) |
| `steam_api.dll`, `steam_appid.txt` | сеть Steam |
| `tmntnet-README.md` | инструкция для игрока |
| `tmntnet-install.txt` | список установленного — по нему работает удаление |

Во время работы мод создаёт рядом:

| Файл | Что это |
|---|---|
| `tmntnet.log` | журнал последнего запуска |
| `tmntnet-logs\` | журналы десяти предыдущих запусков |
| `savegame.dat.bak` | предыдущее сохранение (перед каждой автозаписью) |
| `savegame.dat.netplay`, `savegame-netplay.dat` | у гостя: копия своего сохранения на время общей игры и прогресс общей игры |
| `screenshots\` | снимки экрана по F12 |

**`TMNT.EXE` и остальные файлы игры не изменяются.** Всё, что делает мод, происходит в памяти
запущенной игры.

## Обновление

Лаунчер при каждом запуске проверяет, вышла ли новая версия, и обновляет мод кнопкой
**ОБНОВИТЬ ДО …** ([подробнее](LAUNCHER.md#обновление)). Без лаунчера — запустите новый
`tmntnet-setup.exe` и снова нажмите **«Установить мод»**. В обоих случаях ваш `tmntnet.ini`,
клавиши и сохранения остаются.

> [!NOTE]
> Если в описании релиза сказано, что изменился **сетевой протокол**, обновиться должны все
> игроки: версии с разными протоколами между собой не соединяются.

## Удаление

В лаунчере: настройки (значок справа вверху) → **Удалить мод**, два нажатия. Или запустите
`tmntnet-setup.exe` и нажмите **«Удалить»**. Установщик убирает ровно то, что ставил,
и возвращает файлы, которые лежали в папке до установки (например, чужой `winmm.dll`). Если на
действия были назначены кнопки мыши, им возвращаются клавиши игры; прежний файл настроек игры
остаётся рядом как `savesetting.dat.tmntnet`.

Сохранения (`savegame.dat`) удаление не трогает.

## Установка из командной строки

```text
tmntnet-setup.exe /quiet /host "D:\Games\TMNT"     установить мод без окна
tmntnet-setup.exe /uninstall "D:\Games\TMNT"       удалить
tmntnet-setup.exe /client "D:\Games\tmntnet"       только клиент для режима «игра у хоста»
```

## Если `winmm.dll` уже занят другим модом

Мод можно загрузить и через `dinput8.dll`: возьмите файл из папки `alt-loader` рядом с
установщиком в архиве сборки и положите к `TMNT.EXE` вместо `winmm.dll`. В этом варианте не
работает широкий экран.

## Проверка

После запуска игры рядом с `TMNT.EXE` появляется `tmntnet.log`, а в главном меню — пункт
**СЕТЕВАЯ ИГРА** (вторая строка). Если их нет — см. [«Если что-то не так»](TROUBLESHOOTING.md).
